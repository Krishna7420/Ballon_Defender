# 🎈 Balloon Defender

An exciting fast-paced iOS arcade game where players defend against incoming balloons, test their reflexes, and aim for the highest score!

## 📱 About the Project

**Balloon Defender** is an iOS arcade game built using **Swift** and **UIKit**, designed to deliver engaging gameplay with smooth animations, interactive controls, and score-based progression.

This project demonstrates practical iOS development concepts including:

- UIKit-based UI development
- Game logic implementation
- Collision detection
- Score tracking system
- Animation handling
- Touch interactions
- State management
- MVC architecture

---

## ✨ Features

✅ Fast-paced arcade gameplay  
✅ Smooth balloon movement animations  
✅ Real-time score tracking  
✅ Interactive touch controls  
✅ Game over detection  
✅ Restart / replay functionality  
✅ Clean and responsive UI  
✅ Optimized for iPhone devices  

---

## 🛠 Tech Stack

- **Language:** Swift
- **Framework:** UIKit
- **IDE:** Xcode
- **Architecture:** MVC
- **Platform:** iOS

---

## 🎮 Gameplay

Defend yourself against incoming balloons by interacting quickly and accurately.

The objective is simple:

- Survive as long as possible
- Avoid getting overwhelmed
- Score as high as possible
- Improve your reaction speed
